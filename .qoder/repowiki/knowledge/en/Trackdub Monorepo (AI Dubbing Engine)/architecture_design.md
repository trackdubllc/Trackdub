The root is a .NET solution orchestrator: `Trackdub.slnx` enumerates all `src/*` and `tests/*` csproj files, while `Directory.Build.props` and `Directory.Packages.props` enforce shared compiler flags (net10.0, nullable, implicit usings, treat-warnings-as-errors) and centralized NuGet package versions across every project. `global.json` pins the .NET SDK to 10.0.300+, and `mise.toml` pins dotnet/node/pnpm toolchains for reproducible environments. Solution filters (`Trackdub.Inference.slnx`, `Trackdub.Sdk.slnx`) carve subsets of the full graph for faster iteration. The strict layered dependency direction documented in README.md (Domain → Contracts → Application → Infrastructure/Media/Inference → Composition → Sdk/Cli) is the contract that binds all child modules together; `Trackdub.Composition` is the DI wiring root that resolves the runtime graph at startup.
