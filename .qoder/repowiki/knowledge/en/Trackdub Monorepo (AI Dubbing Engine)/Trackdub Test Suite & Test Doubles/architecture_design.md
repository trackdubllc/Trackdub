The tests are organized as one xUnit project per production layer (Domain, Application, Infrastructure, Media, Inference, Licensing, Sdk, Composition, Architecture, Benchmarks, Onnx), each with its own `*.csproj` and `packages.lock.json`, mirroring the production assembly structure. A separate `Trackdub.TestDoubles` project holds all fake implementations (`FakeTtsEngine`, `FakeTranscriptRepository`, `FakeStudioSettingsService`, etc.) that implement the same interfaces used by production code, so every test project references this shared fixture library rather than duplicating mocks. Conditional integration tests use custom `[Fact]` subclasses (`SmokeTestFactAttribute`, `RequiresTrtRtxFactAttribute`, `RequiresDirectMlFactAttribute`) that compute their `Skip` reason at discovery time based on environment variables (`TRACKDUB_SMOKE_MEDIA_PATH`, `TRACKDUB_TRT_RTX_SMOKE`) and runtime probes. Each test project contains a `README.md` declaring its scope (what belongs / what should not go here) to keep responsibilities isolated. GlobalUsings files centralize cross-cutting imports across projects.
