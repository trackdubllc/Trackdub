Integration/smoke tests require explicit opt-in: set `TRACKDUB_TRT_RTX_SMOKE=1` to run TensorRT RTX tests, place `smoke.mp4` under `Fixtures/` or point `TRACKDUB_SMOKE_MEDIA_PATH` to it, and run `tools/dev/Fetch-TrtRtxEp.ps1` then set `TensorRtRtxProviderConstants.PluginDirectoryEnvironmentVariable` before executing TRT-RTX tests.
